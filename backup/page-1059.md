## Post 14 - Siêu Nhân Toán Học

Nay rảnh ngồi crawl thử mấy web truyện coi công nghệ chống crawl nó update tới mức nào rồi. Nhìn chung thì vẫn là dùng javascript để render canvas xen kẽ với text. Kiểu:

<p>Hắn ta mỉm cười</p>

<render bằng canvas>nàng mỉm cười lại<render bằng canvas>

(một vài thẻ p trống)

<p>Hai người ôm nhau</p>

Thằng metruyencv thì chỉ làm tới đây là hết. Còn cá biệt có một vài web dùng AES để mã hóa nội dung gửi từ server xuống (kiểu thế này):

				"lightbox_thumbnails": "Thumbnails",
				"lightbox_download": "Download",
				"lightbox_share": "Share",
				"lightbox_zoom": "Zoom",
				"lightbox_new_window": "New window",
				"lightbox_toggle_sidebar": "Toggle sidebar"
			}

![Screenshot 2025-07-05 013909.png](https://voz.vn/attachments/screenshot-2025-07-05-013909-png.3125465/)

Như trang web này thì họ show key trong file js trên frontend luôn nên giải mã cũng dễ, nhưng mình sẽ thử tiếp cận theo cách OCR coi sao:

Bước 1: Dùng selenium làm headless browser, disable hết các thẻ sticky fixed, đợi khi nào web chạy xong mã javascript thì screneshot các canvas.

Bước 2: Dùng beautifulsoup lấy những đoạn text không bị bỏ vào canvas

Bước 3: Đánh số thứ tự trong DOM

Bước 4: Dùng PIL để tạo nền trắng cho các thẻ canvas giúp OCR tốt hơn.

![1751655059321.png](data:image/svg+xml;charset=utf-8,%3Csvg xmlns%3D'http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg' width='1600' height='427' viewBox%3D'0 0 1600 427'%2F%3E)

![1751655059321.png](https://voz.vn/attachments/1751655059321-png.3125469/)

Bước 5: Dùng Pytesseract để lấy text từ ảnh (Có thể dùng thư viện khác để lấy text tiếng Việt chuẩn hơn nữa, nhưng mình thử thì thấy đúng 99% nên không cải tiến thêm)

Bước 6: Dùng ThreadPoolExecutor để chạy đa thread giúp crawl nhiều chương 1 lúc

Bước 7: Ghép text lấy từ canvas và text gốc theo đúng thứ tự đã đánh số ở bước 3

![1751655007161.png](data:image/svg+xml;charset=utf-8,%3Csvg xmlns%3D'http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg' width='1393' height='116' viewBox%3D'0 0 1393 116'%2F%3E)

![1751655007161.png](https://voz.vn/attachments/1751655007161-png.3125468/)

Bước 8: Sau khi crawl xong thì lưu vào file json

![1751655186843.png](data:image/svg+xml;charset=utf-8,%3Csvg xmlns%3D'http%3A%2F%2Fwww.w3.org%2F2000%2Fsvg' width='1397' height='644' viewBox%3D'0 0 1397 644'%2F%3E)

![1751655186843.png](https://voz.vn/attachments/1751655186843-png.3125471/)

Bước 9: Từ file json này có thể dễ dàng viết thêm script lưu vào database hoặc tạo epub.

Điểm yếu là tốc độ khá chậm. Mình chạy 5 thread thì mất khoảng 1 tiếng để crawl xong 1300 chương. Nếu tăng số thread lên thì cũng cỡ ~30 phút.

Các bác biết cách nào giúp tăng tốc độ hoặc biết web nào chống crawl tốt hơn thì giới thiệu mình với nhé. Đang vọc cái python.  ![:big_smile:](https://data.voz.vn/styles/next/xenforo/smilies/popopo/big_smile.png?v=01)
